# Food Talker

**Telegram-бот, который отвечает на вопрос «что бы поесть?» обычным языком.**

Спрашиваешь *«что-нибудь острое и недорогое в центре»* — Food Talker разбирает запрос через LLM, ищет по меню ресторанов семантически и отвечает конкретными блюдами, а не списком ссылок.

В этом репозитории лежит сам сервис бота. Retrieval-стек, к которому он обращается — PostgreSQL/pgvector, Qdrant, LightRAG и GPU-реранкер — находится в [food-talker-root](https://github.com/TroExol/food-talker-root).

## Как это работает

1. **Понимание** — сообщение пользователя разбирается LLM в структурированный интент (кухня, ценовой диапазон, ограничения, настроение).
2. **Поиск** — блюда и меню достаются по векторной близости из pgvector, Redis кеширует горячие запросы.
3. **Реранк** — кандидаты пересортировываются отдельным сервисом реранкинга, чтобы ответ соответствовал именно запросу, а не сырой близости эмбеддингов.
4. **Ответ** — результат форматируется и отдаётся в чат Telegram.

Плановые задачи (`node-cron`) в фоне поддерживают данные по меню в актуальном состоянии.

## Стек технологий

| Слой | Технологии |
|------|-----------|
| **Рантайм** | Node.js 22, TypeScript (strict) |
| **Бот** | Telegraf |
| **LLM** | OpenAI SDK |
| **Хранилище** | PostgreSQL (pgvector), Redis, SQLite |
| **Планировщик** | node-cron |
| **Тестирование** | Vitest, `memfs` для подмены файловой системы |
| **Качество** | ESLint (perfectionist, stylistic), Husky pre-commit, strict typecheck |

## Структура проекта

```
src/
├── bot/         # Обработчики Telegram и сценарии диалога
├── services/    # Сервисы поиска, LLM и работы с данными
├── research/    # Эксперименты с retrieval и их оценка
├── config/      # Конфигурация и переменные окружения
├── types/       # Общие TypeScript-типы
├── utils/       # Утилиты
└── index.ts     # Точка входа
```

Тесты лежат рядом с кодом как `*.test.ts`. Внутренние импорты — через алиас `@/`.

## Быстрый старт

### Требования

- Node.js `>=22.15.0 <23`
- npm >= 10
- Поднятый стек [food-talker-root](https://github.com/TroExol/food-talker-root) (как минимум PostgreSQL с pgvector и Redis)

### Установка

```bash
npm install
cp env.example .env    # заполнить доступы Telegram и OpenAI
npm start
```

### Команды

| Команда | Описание |
|---------|----------|
| `npm start` | Локальный запуск через `ts-node` с алиасами путей |
| `npm run typecheck` | Строгая проверка типов без сборки |
| `npm test` | Прогон Vitest один раз (для CI) |
| `npm run test:watch` | Vitest в watch-режиме |
| `npm run eslint:fix` | Линт с автофиксом |
| `npm run lint` | Typecheck + ESLint + тесты (запускается на pre-commit) |

## Соглашения

- Отступ 2 пробела, одинарные кавычки, точки с запятой обязательны, лимит 120 символов.
- Импорты сортируются и группируются через `eslint-plugin-perfectionist`.
- Тесты детерминированные — без сети, без реальной БД и Redis; подменять через интерфейсы.
- Секреты не коммитить; при изменении конфигурации обновлять `env.example`.
